## Project Description
This project uses R to perform preliminary technical analysis on a portfolio of stocks.

The R script:
- Imports stock symbols from `portfolio.txt`
- Downloads stock market data
- Calculates mean, median, mode, standard deviation, and 20-day moving average
- Displays stock data and statistics
- Creates stock price charts

## Files
- `technical_analysis.R` – R code for the technical analysis
- `portfolio.txt` – List of stock symbols used in the analysis
